Configuração da API Pluggy

Informe o identificador da aplicação.

O segredo será criptografado no servidor e não será exibido novamente.

Use somente para testes. Sandbox não está disponível em produção.

Após remover, a configuração do servidor será usada, se disponível. Bancos conectados precisam ser desconectados antes da remoção.

Como a configuração funciona

  1. Selecione a empresa. As credenciais salvas valem apenas para ela.
  2. Valide e salve. A autenticação é verificada com a Pluggy antes de substituir as credenciais atuais.
  3. Consulte os bancos. Verifique os conectores disponíveis para contas e transações.

Salvar as credenciais não conecta contas nem importa extratos. A conexão bancária exige consentimento pelo Pluggy Connect.

Somente administradores e supervisores podem gerenciar esta configuração.
